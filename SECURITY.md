# Security Policy

Last updated: August 2nd, 2026

## Supported versions

Security fixes are provided for the latest version of CAPTURR available on the [App Store](https://apps.apple.com/us/app/capturr-for-roam-research/id6751626906).

Reports affecting the current TestFlight build are also welcome. Older releases are not supported.

## Reporting a vulnerability

Please do not report suspected security vulnerabilities through a public GitHub issue.

Use [GitHub's private vulnerability reporting](https://github.com/plushgraffiti/capturr-ios/security/advisories/new).

Please include:

- The affected CAPTURR version or build.
- The device and operating system version.
- A description of the vulnerability and its likely impact.
- Steps to reproduce it or a minimal proof of concept.
- A suggested mitigation, if you have one.

Never include Roam Research API tokens, graph names or content, personal information, credentials, or other private data. Redact sensitive information from logs and screenshots.

If you believe an API token has been exposed, revoke or rotate it immediately.

Ordinary bugs, feature requests, and support questions may be submitted through public GitHub Issues.

## Response and disclosure

CAPTURR is a free app maintained by a single developer. I aim to acknowledge security reports within seven days and provide an initial assessment within fourteen days. Response and remediation times may vary depending on the issue.

Please allow reasonable time for a vulnerability to be investigated and, where necessary, for a fix to be released before publicly disclosing it.

Reporters may be credited in a published security advisory unless they prefer to remain anonymous.

## Research guidelines

Please:

- Test only with accounts, devices, and data that you own or are authorised to use.
- Avoid accessing another person's data.
- Avoid destructive testing, privacy violations, or disruption to services.
- Stop testing and report the issue if you encounter sensitive information.

## Bug bounty

CAPTURR does not operate a paid bug bounty programme.
